# **App Name**: Dead Drop Loot

## Core Features:

- Loot Categorization: Organize survival essentials into Food, Tools, and Medicine using a tactical folder interface.
- Discovery Toggle: Quick-mark supplies as found or missing with satisfying visual strikethrough and haptic feedback simulations.
- Global Localization Hub: Switch the entire interface between Spanish and English for cross-border survivor coordination.
- Environmental Luminance System: Toggle between High-Visibility Day (light) and Stealth-Optimized Night (dark) themes based on current mission parameters.
- Mission Persistence: Secure inventory state locally so that gear lists are retained through session reloads.
- Supply Intelligence: An AI-powered scout tool that suggests context-aware scavenge lists based on user-inputted urban zones.

## Style Guidelines:

- Primary palette uses an aggressive tactical red (#8B0000) against a neutral rustic base (#EAE6DF) for daytime visibility.
- Stealth-focused night palette swaps to an ember red (#B22222) over a charcoal foundation (#2A2B2A).
- 'Space Grotesk' used for headers to mimic technical digital readouts; paired with 'PT Sans' for warm, readable inventory details.
- Stencil-style military icons for supplies and hazardous UI elements.
- Compact, card-based inventory slots resembling military equipment storage kits.
- Micro-vibrations and glitch-like transitions when toggling found status or shifting environment modes.
